# API guide

Base path `/api/v1`. Protected routes require `Authorization: Bearer <access token>`. The browser uses a same-origin proxy; login/refresh/logout additionally require the exact configured frontend Origin. Private responses use no-store. JSON error envelopes include a code, message and requestId; validation rejects unknown fields. Paginated resources use `page`, `pageSize` (max100) and optional domain filters and return `{ items, total, page, pageSize }`.

DTO classes in each API module define the accepted payloads. Generated OpenAPI TypeScript lives in `apps/web/lib/api/generated.ts`; auth, profile, notifications and error contracts use its public response types. The remaining domain views in `domain.ts` are maintained manually while their response schemas are completed. Revision-bearing forms retain the revision associated with the loaded form. Grade saves require `submissionVersionId`, `rubricRevisionId` and `reviewCycle`; publication requires the exact `gradeRevisionId`, so an old form cannot grade a newer PDF or publish a replacement draft. On409, reload and review current evidence.

After building the API, run `pnpm api:generate` to update `docs/api.openapi.json` and the generated TypeScript together, or `pnpm api:check` to reject drift. Export creates the same Nest dependency graph/document factory as runtime, without connecting to PostgreSQL, starting workers or listening on a port. CI checks drift and formatting. Swagger includes route/security/request DTOs, multipart bodies, shared structured errors, auth/profile/health/notification response schemas and all four private PDF operations with binary200/206 schemas. Success response schema coverage is currently **16/89 operations**; generation deliberately leaves other response bodies unknown. This is not yet a complete external client contract.

Validation errors use `fieldErrors: string[]`; domain-specific field errors may use `Record<string,string[]>`. Both are described in the generated error schema. Locally synthesized frontend errors can lack a server `requestId`.

PDF endpoints authorize every request, then stream inline bytes with Content-Disposition, private no-store caching and optional Range support. File metadata contains display name, size and checksum; storage object keys and publicly reusable object URLs are never client contracts. Archive download policy controls the application download capability; an authorized viewer can still save PDF bytes already delivered to their browser.

An instructor's expanded grading context includes real identities and private evidence. Author-facing review/grade DTOs are separate, and unpublished grading drafts are excluded. Similarity states are PENDING, SUBMITTED_EXTERNALLY, COMPLETED, FAILED and WAIVED; these are textual similarity process states, not automatic plagiarism judgments.
